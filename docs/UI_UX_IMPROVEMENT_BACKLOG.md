# Cysle Egypt — UI/UX & Product Improvement Backlog
## سجل التحسينات وتطوير تجربة المستخدم ومصفوفة الأولويات (P0 - P3)

---

## 1. تصنيف الأولويات المعتمد (Severity Classification)
- **P0 — حرج أمني أو فقدان بيانات (Critical Security / Data Loss)**: يُعالج فوراً قبل أي تشغيل إنتاجي.
- **P1 — عطل تشغيلي مؤثر (High-Impact Workflow Failure)**: يعطل مسار عمل أساسي للمستخدم ويجب إصلاحه في نفس الإصدار.
- **P2 — تحسين هام للاعتمادية وسلاسة الاستخدام (Usability & Reliability Improvement)**: يحسن التجربة اليومية ويمنع الارتباك.
- **P3 — ميزة إضافية أو توسع مستقبلي (Optional Enhancement / Roadmap)**: تطويرات إضافية مجدولة للإصدارات اللاحقة.

---

## 2. المشكلات المكتشفة وما تم معالجته بالفعل (Resolved In Current Sprint)

### [RESOLVED / P1] روابط طلبات الشراء الوهمية بالصفحة الرئيسية المؤدية لـ 404
- **الدور المتأثر**: المشتري (`BUYER`) ومالك المصنع (`FACTORY_OWNER`).
- **المشكلة السابقة**: كان مكون `LatestRfqsSection.tsx` يستعين بمعرفات وهمية (`rfq-1`, `rfq-2`, `rfq-3`) عند عدم وجود طلبات بالدليل، مما كان يولد روابط مكسورة تُظهر خطأ "طلب التصنيع غير موجود" وتُظهر 0 طلب في البورصة.
- **الحل المنفذ**:
  - ترحيل 8 طلبات تصنيع حقيقية كاملة الجداول والمقاسات والمواصفات إلى قاعدة البيانات.
  - إزالة الروابط الوهمية واستبدالها بحالة فارغة أنيقة توجه لنشر طلب جديد عند خلو البيانات.
  - إضافة آلية توجيه ذكي في الـ API تحول المعرفات القديمة لطلبات حقيقية دون أي 404.

### [RESOLVED / P1] ربط موظفي المصنع (Manager, CRM, Production, Warehouse) بالمصنع المشغل
- **الدور المتأثر**: كافة أدوار طاقم المصنع الداخلي.
- **المشكلة السابقة**: كان نموذج `User` يربط المصنع فقط بمالك السجل الأساسي (`userId` في `FactoryProfile`)، مما كان يمنع الموظفين الفرعيين من حل سياق مصنعهم.
- **الحل المنفذ**:
  - إضافة حقل `factoryId` المفهرس لجدول `User` في كلا من SQLite و PostgreSQL.
  - ترقية `resolveFactoryContext` و `login/route.ts` لربط الموظف بمصنعه المشغل فورياً وسيرفرياً.

### [RESOLVED / P2] زر تسجيل المصنع المتكرر للمستخدمين المسجلين
- **الدور المتأثر**: المصانع المسجلة والمشترين المتصفحين لدليل المصانع.
- **المشكلة السابقة**: استمرار ظهور زر "سجل مصنعك الآن" لمالك المصنع المسجل بالفعل.
- **الحل المنفذ**:
  - إنشاء مكون `FactoryDirectoryCta` المعتمد على الجلسة السيرفرية، والذي يستبدل الزر بـ "لوحة تحكم المصنع" لمالك المصنع، و"لوحة المشتري / انشر RFQ" للمشتري، و"لوحة تحكم الإدارة" للمدير العام.
